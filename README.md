# Costume Profit — первая версия PWA

Мобильное приложение для учёта продаж костюмов. Интерфейс на русском, валюта — KGS (сом). Использует Supabase для облачной базы данных, аккаунтов и фотографий.

## Уже реализовано
- Адаптивный интерфейс для телефона и установка как PWA.
- Dashboard: прибыль, выручка, себестоимость, число продаж и маржа.
- Фильтры: сегодня, этот месяц, прошлый месяц, всё время.
- Добавление продажи с фото (камера или галерея), себестоимостью, ценой и заметкой.
- Автоматический расчёт прибыли и маржи.
- История продаж.
- Регистрация/вход по email и паролю через Supabase.

## Подключение облака Supabase
1. Создай проект на https://supabase.com/.
2. Открой **SQL Editor → New query**, вставь весь файл `supabase.sql` и нажми **Run**.
3. Открой **Project Settings → API** (или **Connect**) и скопируй Project URL и anon/publishable key. Не используй `service_role` key в браузере.
4. В `app.js` замени значения в начале файла:
   ```js
   const SUPABASE_URL = 'YOUR_SUPABASE_URL';
   const SUPABASE_ANON_KEY = 'YOUR_SUPABASE_ANON_KEY';
   ```
5. В Supabase → Authentication → URL Configuration укажи адрес опубликованного приложения в Site URL. Для локального теста добавь `http://localhost:8000` в Redirect URLs.
6. Запусти локальный сервер из папки проекта: `python3 -m http.server 8000`, затем открой `http://localhost:8000`.
7. На телефоне открой опубликованный HTTPS-адрес и выбери «Добавить на главный экран» / «На экран Домой».

## Публикация
Можно разместить статические файлы на Netlify, Vercel или Cloudflare Pages. Для PWA нужен HTTPS (кроме localhost). Загрузи содержимое этой папки в выбранный хостинг и добавь полученный URL в Supabase Authentication → URL Configuration.

## Важно
- В первой версии вход — email + пароль. Если регистрация включена с подтверждением email, сначала подтверди письмо.
- Фото загружаются в публичный bucket `costume-photos`: URL изображения публично доступен тому, у кого есть ссылка. Данные о продажах защищены RLS и доступны только владельцу аккаунта.
- Суммы считаются в сомах; прибыль = цена продажи − себестоимость; маржа = прибыль / цена продажи × 100.
